# StudyBuddy AI

StudyBuddy AI היא מערכת לניהול ויצירת מבחנים חכמים המבוססת על סוכני בינה מלאכותית. הפרויקט נולד מתוך צורך אישי לייעל את תהליך הלמידה והפיכת חומרי לימוד גולמיים למבחנים אינטראקטיביים המדמים את המציאות האקדמית.

המערכת מאפשרת למורים ולסטודנטים להעלות קבצים או טקסט חופשי, ומייצרת מהם מבחן מקיף הכולל שאלות אמריקאיות ופתוחות, תשובות נכונות והסברים מפורטים.

## יכולות המערכת

* עיבוד מסמכים: המערכת תומכת בפורמטים PDF, DOCX, PPTX וטקסט חופשי.
* ניהול כיתה: מורים יכולים לייצר קישור ייעודי לתלמידים, לעקוב אחר ציונים בזמן אמת ולראות לוח בקרה של כל ההגשות.
* תרגול עצמי: סטודנטים יכולים להיבחן באופן עצמאי, לקבל ציון מיידי והסבר פדגוגי על כל טעות.
* ייצוא ל-PDF: ניתן להוריד את המבחנים כקבצים מעוצבים להדפסה, בגרסה ריקה או בגרסת פתרונות מלאה.
* התאמה מלאה למובייל: הממשק נבנה בגישת Mobile-First כדי לאפשר למידה נוחה מכל מכשיר.

## ארכיטקטורה (Multi-Agent System)

בניגוד למערכות צ'אט פשוטות, StudyBuddy מבוססת על רשת של סוכני AI העובדים בשיתוף פעולה (MAS) על גבי תשתית LangGraph. תהליך יצירת המבחן מחולק לשלושה שלבים מרכזיים:

1. הארכיטקט: מנתח את חומר המקור ובונה תוכנית עבודה למבחן (נושאים מרכזיים, רמות קושי ומבנה).
2. הפרופסור: סוכן האחראי על כתיבת השאלות, המסיחים וההסברים המקצועיים.
3. המבקר: סוכן בקרת איכות המוודא שהשאלות נאמנות למקור, שהתשובות מדויקות ושהמבחן מאוזן.

## טכנולוגיות

* צד שרת: Python, FastAPI.
* בינה מלאכותית: LangGraph, Google Gemini API.
* בסיס נתונים: SQLite, SQLAlchemy.
* צד לקוח: JavaScript, Tailwind CSS.
* ספרייות נוספות: html2pdf ליצירת מסמכים וספריות עיבוד מסמכים (PyPDF2, Docx).

## התקנה והרצה

1. שיבוט המאגר: git clone https://github.com/asafaharon/StudyBuddy
2. התקנת תלויות: pip install -r requirements.txt
3. הגדרת מפתח API: יש להוסיף את המפתח לקובץ .env תחת GOOGLE_API_KEY.
4. הרצת השרת: uvicorn app.main:app --reload
